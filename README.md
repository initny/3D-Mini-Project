# Analisis Keterkaitan Lingkungan dengan Produktivitas Panen Padi dan Pertumbuhan Produksi Padi per Tahun

# Deskripsi Program Mini Project
Program ini merupakan program yang mengolah data dari dataset tanaman padi di Sumatera Barat. Dataset tersebut diolah hingga menghasilkan produktivitas, pertumbuhan, dan hubungan faktor lingkungan terhadap produksi padi. Program ini dilengkapi dengan validasi pembacaan data seperti baris, kolom, dan header. Selain itu, program ini turut menggunakan modularisasi dengan fungsi-fungsi yang saling berhubungan. Program menampilkan beberapa pilihan menu yang dapat dipilih oleh pengguna dan menghasilkan olahan data terkait pilihan tersebut.

# Latar Belakang dan Kegunaan Program
Program dibuat berdasarkan dataset mentah tanaman padi di Sumatera Barat yang memerlukan analisis lebih lanjut. Selain itu, dataset tersebut perlu ditentukan pola hubungan antara produksi dengan faktor lingkungan sehingga dapat menentukan prediksi untuk tahun mendatang. Program ini dapat digunakan oleh pemerintah terutama pemerintah daerah Sumatera Barat untuk membuat perancanaan bagi petani padi di Sumatera Barat. Selain itu, petani daerah dan masyarakat luat dapat menggunakan program ini untuk mempertimbangkan tindakan dan perawatan untuk padi yang sesuai dengan kondisi faktor lingkungannya dan menambah pengetahuan mengenai perkembangan petani padi di Sumatera Barat.

# Fitur Program
Program memiliki beberapa fitur yang dapat digunakan oleh pengguna, sebagai berikut.
1. Menu pilihan yang dapat dipilih oleh pengguna.
2. Menampilkan hasil analisis perhitungan data.
3. Menampilkan hasil yang diinginkan oleh pengguna.

# Cara Penggunaan Program
Program memiliki tiga opsi pada menu utama, yaitu fitur untuk menampilkan hasil analisis atau rekapitulasi data, fitur analisis lanjutan, dan opsi untuk keluar dari program. Fitur analisis lanjutan memiliki dua fitur utama, yaitu analisis tahun tertentu dan perbandingan pertumbuhan dua tahun yang berbeda, serta satu fitur lanjutan berupa prediksi tahun. Berikut merupakan tahapan untuk mengakses fitur-fitur pada Program Analisis Keterkaitan Lingkungan dengan Produktivitas Panen Padi dan Pertumbuhan Produksi Padi per Tahun.
1. Cara Menampilkan hasil analisis / rekap data
Pengguna dapat memilih opsi a pada menu utama untuk menampilkan tabel rekapitulasi data historis. Tabel tersebut memuat informasi tahun, provinsi, produktivitas, pertumbuhan, curah hujan, kelembapan, dan suhu. Tekan Enter untuk kembali ke menu utama.
2. Cara Mengakses Analisis tahun tertentu
Pengguna dapat memilih opsi b, kemudian opsi 1 untuk mengakses fitur analisis tahun tertentu. Selanjutnya, masukkan tahun yang ingin dianalisis. Program akan menampilkan persentase produktivitas, laju pertumbuhan produksi, serta klasifikasi curah hujan, kelembapan, dan suhu rata-rata pada tahun tersebut.
3. Cara Melihat prediksi tahun lanjutan
Fitur ini merupakan lanjutan dari analisis tahun tertentu. Pengguna diminta memasukkan jumlah tahun ke depan yang ingin diprediksi. Program kemudian menampilkan hasil prediksi produktivitas, pertumbuhan, curah hujan, kelembapan, dan suhu berdasarkan tahun yang telah dipilih sebelumnya. Tekan Enter untuk kembali ke menu analisis lanjutan.
4. Cara Membandingan pertumbuhan dua tahun yang berbeda 
Pengguna dapat memilih opsi b, kemudian opsi 2 untuk mengakses fitur perbandingan pertumbuhan. Selanjutnya, masukkan dua tahun berbeda yang ingin dibandingkan. Program akan menampilkan pertumbuhan produksi masing-masing tahun berdasarkan tahun sebelumnya beserta selisih laju pertumbuhan antara kedua tahun tersebut.
